# French electronic invoicing specification 3.2

The `e-reporting` directory contains the unmodified F10 XSD files published by
the French tax administration in external specification version 3.2 dated
30 April 2026.

- official page: <https://www.impots.gouv.fr/specifications-externes-b2b>;
- official archive: `specifications-externes-v3.2.zip`;
- archive SHA-256:
  `cd8f6e817e37f329e6f62a35aa131b78a51379bec953445b774fa8adbaaa3862`;
- source path: `3- XSD_v3.2/1 - E-reporting/`.

These schemas cover the XML envelope and the transaction, payment, report,
and parameter structures of flux F10. Semantic and directory checks performed
by the PPF or an accredited platform remain external to local XSD validation.
